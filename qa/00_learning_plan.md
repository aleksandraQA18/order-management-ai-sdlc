# QA Learning Plan --- This Project

## Primary Goal

Become comfortable with the engineering side of QA by learning through
delivery of real stories.

## Skill Priorities

1.  TypeScript
2.  Playwright
3.  REST/API automation
4.  Git/GitHub
5.  SQL
6.  CI/CD
7.  Docker
8.  Test architecture
9.  Risk-based test design
10. Security basics
11. AI SDLC / agent collaboration

## Learning Rule

Do not learn a technology in isolation if it can be learned through the
current story.

Example: - story requires API test → learn APIRequestContext - story
requires test data → learn fixtures/factories - story reaches CI → learn
GitHub Actions - story requires environment → learn Docker - story
creates access control → learn security testing

## Success Criteria

At the end, you should be able to explain every important test and
pipeline decision without relying on AI.
